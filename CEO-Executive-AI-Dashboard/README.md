# CEO Executive AI Dashboard

A complete, production-ready hospital management dashboard that provides a single-screen overview of critical KPIs, department performance, and AI-powered executive insights.

## Features

- **KPI Summary**: Tracks Total Revenue, Patients, Bed Occupancy, Admissions, Discharges, Emergency Cases, and Patient Satisfaction with trend arrows.
- **Revenue Insights**: Visualizes monthly revenue trends and departmental breakdowns.
- **Department Performance**: Lists patient counts, revenue, occupancy, and dynamically generated performance scores by department.
- **Critical Alerts**: Generates rule-based alerts from live metrics (e.g., high occupancy, low satisfaction).
- **AI Executive Insights**: Connects to DeepSeek via OpenRouter to generate an executive summary, risks, and actionable recommendations based on real-time aggregated PostgreSQL data.
- **Interactive Filtering**: Dynamic Date Range and Department filters that instantly refresh all metrics.

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Recharts, Lucide React
- **Backend**: FastAPI, SQLAlchemy, Pydantic
- **Database**: PostgreSQL
- **AI Integration**: DeepSeek (via OpenRouter) or OpenAI

## Setup Instructions

### 1. Database Setup

Ensure PostgreSQL is running on your machine.
Create a database named `hospital_dashboard` (or update `.env` to match your existing setup).

### 2. Backend Setup

```bash
cd backend
python -m venv venv
# Activate venv: `venv\Scripts\activate` (Windows) or `source venv/bin/activate` (Mac/Linux)
pip install -r requirements.txt
```

### 3. Environment Variables

Copy `backend/.env.example` to `backend/.env` and update your OpenRouter API key:

```env
AI_PROVIDER=openrouter
OPENAI_API_KEY=your_openrouter_api_key_here
OPENAI_BASE_URL=https://openrouter.ai/api/v1
OPENAI_MODEL=deepseek/deepseek-chat
```

### 4. Seed Database

This will drop existing tables and populate the database with realistic hospital data for the last 6 months.

```bash
cd backend
python scripts/seed_db.py
```

### 5. Run Backend Server

```bash
cd backend
uvicorn app.main:app --reload --port 8000
```

### 6. Run Frontend Server

```bash
cd frontend
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`.

## Demo Flow

1. Open the dashboard at `http://localhost:5173`.
2. View the complete KPI summary and Revenue trends representing the past 30 days (default).
3. Check the **Department Performance** to see which department is underperforming.
4. Review **Active Alerts** generated by rule-based thresholds on actual metrics.
5. Filter by "Emergency" or select a different date range. Watch the entire dashboard (including trends) adapt.
6. Click **Refresh AI Insights** (or wait for automatic loading) to see DeepSeek's analysis of the specific filtered data, yielding actionable, structured recommendations.
